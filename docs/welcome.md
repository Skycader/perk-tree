# Добро пожаловать в «Древо» — читать первым

> Этот файл — точка входа для любой нейросети (или человека), которая видит
> проект впервые, например после потери истории чата. Прочитай его целиком,
> затем иди по оглавлению ниже. Автору **не нужно** заново объяснять, что это
> за проект: всё, что нужно для старта, лежит в репозитории.

## Что это за проект (за 60 секунд)

**«Древо» (Perk Tree)** — личный веб-инструмент одного автора (Skycader,
Устименко Даниил). Это интерактивное дерево способностей («перков») для
вымышленной системы силы из литРПГ/сверхспособностей-романа, и одновременно
личная справочная база по этому сеттингу: у каждой способности есть уровни
(0–10) с физическими величинами, картинки/видео/аудио, комбо-способности,
лорные заметки («Заметки неизвестного») и мини-вики-статьи.

- **Стек:** чистые HTML + CSS + JavaScript (ES-модули). Без сборщика, без
  фреймворка, без `package.json`. Открывается статическим сервером.
- **Язык контента:** русский (UI, проза, данные). Комментарии в коде — на
  английском. Держи это разделение.
- **Данные:** вся «игровая» информация лежит в JS-конфигах
  (`configs/<имя>/<имя>.config.js`), а не в коде приложения. Приложение —
  это движок, конфиг — это контент. Выбор конфига — параметр URL
  `?config=<имя>` (по умолчанию `default`).
- **Автор один**, итерации короткие, исправления часто мгновенные и
  краткие. См. [collaboration.md](../claude/collaboration.md).

## Быстрый старт

```bash
python .claude/nocache_server.py 8199
```

Открыть `http://localhost:8199` (никогда не `file://` — ES-модулям нужен
http). Другие конфиги: `?config=blank` (пустой шаблон), `?config=vampire`
(демо-архетип, черновик). Подробнее — [workflow.md](workflow.md).

## Правила работы (важное, нарушать нельзя)

1. **Сначала прочитай `CLAUDE.md`** в корне — он автозагружается и ведёт в
   `claude/*.md` для опасных областей (SVG, зум, мобильная раскладка,
   каскад попапов и т.д.). Перед правкой области — читай её файл.
2. **Проверяй в реальном пути использования**, а не на удобной подмене.
   Проходящих DOM-проверок недостаточно; см.
   [claude/dev-workflow.md](../claude/dev-workflow.md).
3. **Контент конфигов — это нагрузочные данные**, а не заглушки: числовые
   пороги, физические единицы, зависимости комбо (`combo`, `requiredPerks`,
   `skillLevelDescriptions`) согласованы между собой. Не «улучшай» их
   без запроса. Лор про души/амюоны — [claude/lore.md](../claude/lore.md).
4. **Не добавляй лишнего.** Правка бага — это правка бага. Без рефакторинга
   «заодно», без новых абстракций «на будущее».
5. **Неотвеченный вопрос — не согласие.** Если вопрос к автору остался без
   ответа, остановись и жди, не выбирай «рекомендуемый» вариант сам.
6. **Коммиты/пуши — только по просьбе.** Remote'ов два: `origin` (GitHub) и
   `origin-gitlab` (GitLab); «commit and push» автор обычно имеет в виду
   в оба. Подпись коммитов — по актуальной инструкции сессии.
7. **Планирование крупных изменений** идёт через OpenSpec (`openspec/`).
   См. [workflow.md](workflow.md).

## Состояние проекта

- **Версия движка:** 0.9 (см. `CHANGELOG`; номер показан в верхней панели).
- **Основной контент:** `default` — 55 перков в 3 колонках, ~40 комбо,
  ~100 заметок, 5 вики-статей.
- **Недавно сделано:** окно поиска (4 типа, фильтры, `F`), импорт заметок из
  Obsidian, встраивание файлов `<file src>`, `switchMode: 'tabs'` для
  нескольких картинок в одном окне.
- **Чего пока нет:** редактирование в браузере (всё через правку JS-конфига),
  валидации конфига, мультиязычности, обратных ссылок «кто ссылается на
  заметку». Живой список идей — [../todo.md](../todo.md).
