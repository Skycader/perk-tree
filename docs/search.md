# Окно поиска

Реализация: `js/search-modal.js`, стили `css/search.css`, разметка в конце
`index.html` (`#search-modal`). Нормативное описание поведения —
`openspec/specs/content-search/spec.md` (актуально по основным требованиям).

## Как открыть

- Кнопка-лупа в верхней панели (между номером версии и кнопками масштаба);
- клавиша **F** (физическая клавиша `KeyF`, поэтому работает и в русской
  раскладке, где она даёт «а»). Не срабатывает, если фокус в текстовом
  поле/`textarea`/contenteditable или зажаты Ctrl/Alt/Meta;
- закрыть: ×, Esc, клик по затемнению.

При открытии поле ввода получает фокус сразу, запрос и поле очищаются;
выбор фильтров сохраняется до перезагрузки страницы.

## Что ищется

Индекс строится один раз при загрузке модуля из четырёх источников:

| Тип | Источник | Карточка |
| --- | --- | --- |
| Перк (`ability`) | `CONFIG.skills[].perks[]` — `name` + `description` | Цветной квадрат категории, заголовок, описание |
| Комбо (`combo`) | `CONFIG.skillLevelDescriptions[хозяин].combo[партнёр]` — имя из `==Название==` + `desc` | Квадрат цвета **хозяина**, заголовок, описание |
| Заметка (`note`) | `default.notes.js` — `title` + `content` | Карточка без квадрата |
| Вики (`tip`) | `default.tips.js`; тело берётся **fetch'ем** из `<file src>` | Карточка без квадрата |

Не ищется по построчным описаниям уровней (`skillLevelDescriptions[id][0..10]`).
Поиск — регистронезависимая подстрока; пустой запрос показывает **всё**
(режим «обзор»). Без пагинации: один прокручиваемый список и счётчик
«N результатов».

## Фильтры по типам

Четыре чекбокса под полем: **Перки · Комбо · Заметки · Вики**, все включены.
Последний включённый блокируется (`disabled` + подсказка), чтобы список не
стал пустым. Фильтры комбинируются с запросом.

## Карточки

- Описание рендерится через тот же рендерер, что и в приложении
  (`renderLevelMD` для перков, `renderMD` для остального), совпадения
  подсвечиваются `<mark>`.
- Картинки (`![[файл.png]]`, `<img>`) и таблицы заменяются плашками
  «🖼️ Изображение» / «📊 Таблица» (быстрее и не раздувает высоту).
- Высота адаптивная; у **заметок и вики** описание длиннее ~9.5rem
  обрезается с градиентом и «…» (перки/комбо не обрезаются).

## Клик по карточке

- Перк/комбо: окно закрывается, дерево скроллится к перку (для комбо — к
  хозяину), перк подсвечивается через `focusPerkById` (`js/perk-focus.js`).
- Заметка/вики: открывается обычный каскад-попап, окно поиска остаётся
  открытым (карточки помечены `.note-link-trigger`, чтобы глобальный
  «клик снаружи» не закрывал только что открытый попап).

## Известные нюансы

- Если описание перка содержит `<perk>`-ссылку, она кликабельна внутри
  карточки и сработает вместе с кликом по карточке.
- Совпадение внутри `==…==` даёт вложенные `<mark>` — это нормально.
- `computer{key}` в песочнице не заполняет `event.code` — для проверки `F`
  используй синтетический `KeyboardEvent` (см. `claude/dev-workflow.md`).
