# Формат конфига

Пример-эталон — `configs/default/default.config.js`; минимальный
структурно-полный шаблон — `configs/blank/blank.config.js`. Файл
экспортирует `export const CONFIG = { ... }`. Валидации нет: опечатка в id
молча ничего не покажет.

## Верхний уровень

| Ключ | Тип | Назначение |
| --- | --- | --- |
| `shadowName` (или `name`) | string | Название стэнда в шапке (`shadowName` приоритетнее; `vampire` использует `name`) |
| `logo` | string | Эмодзи вместо оранжевого квадрата в шапке |
| `desc` | string | Подзаголовок |
| `version` | string | Версия конфига (бейдж внизу справа) |
| `user` | string | Имя носителя (в коде приложения не используется, для автора) |
| `range_columns` | string[] | Колонки таблицы рангов, напр. `['RANGE','NAME','LOGO']` |
| `maxLevelPerSkill` | number | Макс. уровень перка (по умолчанию 10) |
| `tags` | `{title, array[]}` | Блок тегов-алиасов под шапкой |
| `spectre` | `{red,orange,yellow,blue,green,purple,black}` | Описание каждой цветовой категории (попап по клику на лого) |
| `skills` | Chapter[] | Главы и перки (см. ниже) |
| `ranks` | `{lvl,name,badge}[]` | Ранги; диапазоны уровней считаются динамически |
| `vulns` | `{name,desc}[]` | Нижняя панель «Опасности/уязвимости» |
| `skillLevelDescriptions` | object | Описание уровней, комбо, extended — по id перка |

## Глава (`skills[]`)

```js
{ chapterTitle: '1. Базовые характеристики', color: 'Yellow', perks: [ ... ] }
```

`color`: `Orange | Red | Blue | Green | Purple | Yellow | Black` (регистр не
важен; без `color` назначается автоматически по циклу). Перки главы
наследуют её цвет. Главы раскладываются по 3 колонкам жадно — по числу перков.

## Перк (`perks[]`)

| Поле | Назначение |
| --- | --- |
| `id` | Уникальный id (ключ в `skillLevelDescriptions`, `requiredPerks`, `<perk>`) |
| `name`, `description` | Название и краткое описание в дереве (Markdown) |
| `requiredPerks` | id перков-зависимостей → иконка-цепочка и коннекторы |
| `img` / `imgs[]` | Медиа: строка-путь или `{src,title,desc,audio,height,controls}`; `.png/.jpg/.gif/.mp4` |
| `switchMode` | При ≥2 `imgs`: `'none'` (отдельные окна, по умолчанию) · `'slider'` (одно окно, точки) · `'tabs'` (одно окно, вкладки вместо заголовка). Старое `slider: true` = `'slider'` |
| `fit` | `false` — не обрезать видео (по умолчанию заливка) |
| `audio` | Кнопка-динамик на видео |
| `audios[]` | Аудиодорожки с субтитрами `00:30 - текст` |
| `snippets[]` | `{title,src,size:'WxH',desc,fullScreen}` — HTML-страница в iframe |
| `extra` | Markdown-окно «extra» (длинный текст/таблица) |
| `tip` | Короткое окно-подсказка |
| `positions` | `{combo:3, extra:1, …}` — колонка (1/2/3) для вида окна |
| `priority` | Порядок видов окон для этого перка, напр. `['COMBO','IMG']` |
| `order` | `'from_left'` / `'from_right'` — сторона заполнения |

Подсказка по размерам: у картинок/видео размер читается из имени файла
`name_1920_1080.mp4`, окно резервируется до загрузки.

## `skillLevelDescriptions[perkId]`

```js
shadowStrength: {
  0: 'Подъём до 80 кг / Удар до 200 Дж … \n[ТИП] …',   // уровень 0..N
  1: '…',
  '5:shadowVisor': '…',     // подстрока уровня 5: цветной квадрат перка + свой текст
  combo: { … },             // комбо-способности
  extended: …,              // расширенные данные; хранятся рядом с combo (см. tooltip.js)
}
```

- Ключ `N` — строка уровня N (Markdown, поддерживает `\n`, `- `-списки,
  метки вроде `[ЛИМИТ]`).
- Ключ `N:perkId` — подстрока под уровнем N с квадратом другого перка.
- Любые другие ключи, кроме `combo` и `extended`, игнорируются.

### Комбо

```js
combo: {
  shadowEnergyCapacity: {            // id партнёра-перка
    reqLvl: 2,                       // с какого уровня комбо открывается
    desc: `==Поморгай дальним== Тень способна …`,   // Markdown; ==Название== в начале = имя комбо
    perks: [{ lvl: 3, perk: 'otherId' }],           // (опц.) ещё созависимые перки
  },
}
```

- Комбо **показывается в тултипе хозяина** (перка, под чьим ключом лежит
  `combo`), а партнёр — ключ внутри. В поиске комбо-карточка ведёт к
  перку-хозяину.
- Имя комбо — ведущий `==Название==` в `desc`; без него поиск подставит
  «Комбо: <имя партнёра>».
- Известные шероховатости данных: бывали записи с пустым `combo`,
  несогласованные `reqLvl`/`lvl` внутри `perks[]` — проверяй при правках.

## Заметки и подсказки

`configs/<имя>/<имя>.notes.js` → `export const notes = [{ id, title, content, author }]`.
`configs/default/default.tips.js` → `export const tips = [ … ]` (та же форма).

- `title` уже содержит эмодзи (`'📜 Тень Души'`), `author` — тире
  (`'— Заметки неизвестного.'`); не добавляй их повторно.
- `content` — Markdown; может содержать `<note id>`, `<tip id>`,
  `[[#Заголовок|текст]]`, `==…==`, `<file src="wiki/tips/x.md"></file>`.
- id не уникальны принудительно: дубликат перекрывается первой записью.
- Подсказки пока берутся только из `default.tips.js` (не по `?config`).
- Импорт заметок из Obsidian: `node tools/import-obsidian-notes.js
  [input.md] [output.js]` — ссылки `[[#Заголовок|текст]]` превращаются в
  `<note id>`, id — транслитерация заголовка. Вручную проверь id,
  на которые ссылается конфиг (например `angelskie-slyozy`).

## Разметка внутри текста

| Синтаксис | Результат |
| --- | --- |
| `==текст==` | Выделение `<mark>` |
| `<perk>id</perk>` / `<perk name="id">метка</perk>` | Цветной квадрат/метка; клик → скролл к перку |
| `<note id="x">метка</note>`, `[[#Заголовок\|метка]]`, `[[id:x\|метка]]` | Ссылка на лорную заметку (каскад-попап) |
| `<tip id="x">метка</tip>` | Ссылка на вики-подсказку |
| `<square color="#hex">` | Инлайн-цветной квадрат |
| `<svg name="tip">`, `<svg name="warning">` | Встроенные иконки |
| `<line-break>`, `<empty-line>` | Ручной контроль переносов |
| `<file src="путь.md"></file>` | Подставляет содержимое внешнего файла |

Полное описание и причины порядка обработки — [../dev-wiki/NOTES_SYSTEM.md](../dev-wiki/NOTES_SYSTEM.md).
