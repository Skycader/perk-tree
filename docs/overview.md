# Обзор проекта

## Что это

**«Древо способностей»** — веб-приложение-справочник для вымышленной системы
силы (литРПГ / сверхспособности). Открываешь страницу — видишь дерево из 55
способностей, сгруппированных в главы по трём колонкам. Клик по иконке
способности открывает тултип: уровни 0–10 с числами и единицами измерения,
а рядом — вторичные окна с картинками, видео, аудио, длинным текстом,
подсказками и комбо.

Это одновременно:

- **интерфейс** — красивый «военный HUD» для просмотра способностей;
- **личная база знаний автора** — в ней живёт лор (заметки), вики-справки
  и инженерные расчёты вымышленных способностей.

Автор — один человек, не профессиональный программист, но технически
свободный; ценит инженерную строгость (физические единицы, согласованность
ссылок между перками), применённую к вымышленному контенту.

## Для кого

Для самого автора (черновая работа над сеттингом) и для читателей/игроков,
которым он показывает результат. Это **не** общий конструктор: конфиг —
единственное «API» контента, редактирование идёт правкой JS-файла.

## Что умеет (по областям)

Полная таблица возможностей с указанием файлов — в [../about.md](../about.md).
Кратко:

- **Дерево:** главы по 3 колонкам, цветовые категории (7 цветов), линии-
  коннекторы под 90°, цепочки зависимостей (`requiredPerks`), таблица рангов,
  блок «Опасности» (`vulns`), теги-алиасы, попап «спектра» по клику на лого.
- **Тултип способности:** построчные уровни, навигация по уровням, тайловая
  раскладка вторичных окон (картинки/видео, сниппеты, аудио, «extra»-текст,
  подсказка, комбо) с автопереливом в соседнюю колонку.
- **Медиа:** `img`/`imgs[]` (картинки, gif, mp4), режимы переключения
  `switchMode: 'none' | 'slider' | 'tabs'`, аудиодорожки с субтитрами,
  `snippets[]` — готовые HTML/JS-страницы в iframe.
- **Текст:** Markdown + `==выделение==`, ссылки `<perk>`, `<note>`, `<tip>`,
  вики-ссылки `[[#Заголовок|текст]]`, подключение файлов `<file src>`.
- **Заметки и вики:** лорные «Заметки неизвестного» (~100) и вики-статьи
  из `wiki/tips/`, каскадные попапы «лесенкой» — см.
  [../dev-wiki/NOTES_SYSTEM.md](../dev-wiki/NOTES_SYSTEM.md).
- **Поиск/фильтрация:** окно по кнопке-лупе или клавише `F` — см.
  [search.md](search.md).
- **Движок/UX:** UI-зум 50–200 % и открытый перк хранятся в URL
  (`?zoom=`, `?perk=`), мобильные вкладки, экспорт дерева в PNG, модалка «Лицензия/
  Обновления», загрузочный экран с подсказкой, звёздное небо на canvas.
- **Несколько «стендов»:** `?config=<имя>` подгружает свой набор перков,
  рангов, заметок.

## Чего нет (сознательно или пока)

Редактора в браузере; валидации конфига (несуществующий id в
`requiredPerks`/`combo` просто не отобразится); мультиязычности;
обратных ссылок; гарантии уникальности id заметок (дубликаты возможны —
побеждает первая запись). Идеи и планы — [../todo.md](../todo.md).
