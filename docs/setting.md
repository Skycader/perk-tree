# Сеттинг (краткая выжимка)

> Это справочная выжимка из конфига и заметок, чтобы нейросеть понимала
> терминологию. **Источник истины — сам контент** (`default.config.js`,
> `default.notes.js`, `claude/lore.md`). При расхождении прав контент.

## Главная идея

Метафизика (душа, память, личность, сознание) описывается с той же
инженерной строгостью, что и физика: измеряемые диапазоны, пороги,
деградация при перегрузке. Для этого сделана ключевая оговорка: **что такое
амюоны (частицы души) — неизвестно, известно только, как они себя ведут**
(как физики знают поведение мюона, не зная его «сущности»). Подробнее и с
правилами согласованности — [../claude/lore.md](../claude/lore.md).

## Термины, которые встретишь в контенте

| Термин | Смысл (из репозитория) |
| --- | --- |
| **Стэнд / «Homo Deus»** | Набор способностей одного носителя; в коде — один `CONFIG` (`shadowName`). Заголовок default-конфига — «Homo Deus». |
| **Тень** | Способность-«оболочка» хозяина: у неё уровни, физические параметры, ограничения; большинство перков — это умения Тени. |
| **Ангел, Властитель, хозяева тени** | Роли/существа в мире; видны в тегах, «Опасностях» и заметках. Тело Ангела остаётся смертным; душа Властителя обладает огромной массой и резонансом. |
| **Амюоны, Анима/Анимус** | Частицы, из которых состоит душа; Анима — «душа», связь Анимус↔Анима описана в todo и заметках. Тело, построенное амюонами с нуля, — клон, не человек. |
| **Омут, Пустота, Твари Пустоты** | Элементы мироустройства из заметок; Тварей Пустоты могут видеть только люди с силой тени души, развеять — только силой Тени. |
| **Маяки (бикон)** | Способность/объекты, работающие через Омут; есть комбо с манипуляцией материей. |
| **Заметки неизвестного** | Лорные записки (~100) — «in-universe» тексты. Подписаны «— Заметки неизвестного». |
| **Подсказки / вики** | Внеигровые пояснения механик и физики (`default.tips.js`, `wiki/tips/*.md`): эффект Допплера, бег по воде, визуальный спектр. |

## Семь цветовых категорий

Цвет главы = информация, не декор. Описания лежат в `CONFIG.spectre`
(видны в попапе по клику на лого в шапке):

| Цвет | Смысл |
| --- | --- |
| Красный | Разрушительные способности: всё, что стремится разрушать и убивать |
| Оранжевый | Граничит с разрушением, но не обязательно оружие |
| Жёлтый | Энергетические: всё, что напрямую связано с энергией |
| Синий | Информационные, временные и исключительно защитные |
| Зелёный | Биологические: жизнь, метаморфозы, сотворение |
| Фиолетовый | Паранормальные: измерения, ноосфера, душа |
| Чёрный | Разделение и манипуляция душой |

Цвета и их hex — `js/constants.js` (`COL_HEX`, `ICON_HEX`); цвета категорий
жёстко связаны с главами, не меняй их произвольно.

## Как писать новый контент в этом духе

- Числа с единицами (кг, Дж, МПа, км, нм), конкретные реперные точки
  (оружие, техника, природные явления).
- Уровни растут монотонно; формулировки типа `[ЛИМИТ]`, `[ТЯЖЕСТЬ]`,
  `[МОНОЛИТ]` — это метки стадии на уровне (см. `skillLevelDescriptions`).
- Любой перк/заметка про душу, память, клонирование, одержимость —
  согласуй с `claude/lore.md`.
