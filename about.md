Таблица того, что реально есть в проекте на сегодня:

| Категория                  | Возможность                                                                                                      | Где реализовано                   |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| **Текст**                  | Markdown (жирный, курсив, списки, таблицы, цитаты, код, `<hr>`)                                                  | js/markdown.js + `marked.min.js`  |
|                            | `==выделение==` → `<mark>`                                                                                       | `processHighlightTags`            |
|                            | `<line-break>`, `<empty-line>` — ручной контроль переносов                                                       | `renderMD`/`renderLevelMD`        |
|                            | `<file src="wiki/tips/....md">` — подключение внешнего md-файла                                                  | markdown.js                       |
|                            | `<square color="#hex">` — цветной квадратик инлайн                                                               | `processSquareTags`               |
| **Кросс-ссылки**           | `<perk>`/`<perk name="id">label</perk>` — клик → скролл+подсветка нужного перка                                  | markdown.js + main.js             |
|                            | `<note id>` — лорные заметки («Заметки неизвестного»), каскадные всплывающие попапы «лестницей»                  | notes.js + note-link-popup.js     |
|                            | `<tip id>` — OOC-пояснения механик, тот же движок, другой цвет                                                   | tips.js                           |
|                            | `[[#Title\|label]]` / `[[id:x\|label]]` — вики-ссылки на заметки                                                 | processWikiLinkTags               |
|                            | Цепочки зависимостей (`requiredPerks`) — иконка-цепочка с тултипом и переходом к перку                           | tree.js                           |
|                            | Комбо-перки — несколько созависимых перков/уровней в одной записи                                                | tooltip.js                        |
| **Медиа**                  | `img` / `imgs[]` — картинки, gif, `.mp4` (автоплей, без звука, без контролов)                                    | tooltip.js                        |
|                            | Слайдер (`slider:true`) с точками-навигацией **или** несколько отдельных окон                                    | tooltip.js                        |
|                            | `desc` под картинкой (markdown), скролл вместо обрезания при нехватке места                                      | tooltip.js + windows.css          |
|                            | `height:'maximum'` — заливка окна без леттербоксинга                                                             | tooltip.js                        |
|                            | `controls:true` — кнопка «развернуть» видео в лайтбокс с нативными контролами                                    | video-lightbox.js                 |
|                            | `audio:true` — кнопка-динамик на видео                                                                           | tooltip.js                        |
| **Аудио**                  | `audios[]` — полноценные аудиодорожки: play/pause, прогресс-бар с перемоткой, громкость, тайминг                 | tooltip.js                        |
|                            | Субтитры/«SRT» (`00:30 - текст`) — построчный текст, синхронный с плеером                                        | tooltip.js                        |
| **Сниппеты** _(новое)_     | `snippets[]` — готовые `.html`-страницы **со своим JS** в iframe, размер как у картинки (`size:'WxH'`)           | tooltip.js + snippet-lightbox.js  |
|                            | `fullScreen:true` — та же кнопка-разворот, что у видео, но для iframe                                            | snippet-lightbox.js               |
| **Раскладка окон**         | Тайловая система вторичных окон (IMG/SNIPPET/AUDIO/EXTRA/TIP/COMBO), приоритеты, авто-перелив в соседнюю колонку | windows.js + tooltip.js           |
|                            | `positions`/`priority`/`order` — ручной оверрайд стороны/порядка окон на уровне перка                            | tooltip.js                        |
| **Персонализация/конфиги** | Несколько «стендов» через `?configName=` — свой набор перков/рангов/уязвимостей                                  | load-config.js, `configs/<name>/` |
|                            | Свои заметки на конфиг (`<name>.notes.js`), с тихим фолбэком на «нет заметок» вместо чужого лора                 | load-notes.js                     |
|                            | 7-цветная система категорий, авто- или ручное назначение                                                         | constants.js/tree.js              |
| **UX/движок**              | UI-зум 50–200% с сохранением, отдельно от браузерного zoom                                                       | zoom.js                           |
|                            | Мобильная адаптация — вкладки вместо колонок (`MOBILE_ADAPT`)                                                    | mobile-tabs.js/css                |
|                            | Восстановление открытого тултипа по F5 (sessionStorage + автоскролл)                                             | tooltip.js/main.js                |
|                            | Экспорт дерева в PNG                                                                                             | export-png.js                     |
|                            | Модалка «Лицензия/Обновления» с вкладками из markdown                                                            | license-modal.js                  |
|                            | Загрузочный экран с искусственной задержкой + случайная подсказка                                                | index.html/notes.js               |
|                            | Отладочный `window.dbl()` — снимок геометрии окон/коннекторов + визуальные оверлеи                               | debug.js                          |
|                            | Навигация по уровням тултипа (дропдаун «перейти к уровню»)                                                       | tooltip.js                        |
|                            | Таблица рангов с динамическими диапазонами уровней и бейджами                                                    | tree.js                           |
|                            | Блок «Опасности/уязвимости»                                                                                      | tree.js                           |

**Чего пока нет** (на случай если ищешь дыры): поиск по контенту, тегирование/фильтрация перков, история изменений, редактирование прямо в браузере (всё через правку JS-конфига), мультиязычность, обратные ссылки «кто ссылается на эту заметку», уникальность id заметок не валидируется (дубликаты уже есть, тихо перекрываются).
